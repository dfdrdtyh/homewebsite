# 🚀 我的个人主页项目 (My Personal Homepage)

这是一个基于 HTML5 + CSS3 开发的极简深色毛玻璃风格个人导航主页，托管于 GitHub Pages。

## ✨ 功能特点
- 🎨 **现代 UI 设计**：深色渐变背景搭配毛玻璃（Backdrop Filter）卡片效果
- ⏰ **实时动态时钟**：原生 JavaScript 驱动的本地时间显示
- 📱 **响应式布局**：完美适配电脑端与手机端屏幕
- ⚡ **零依赖**：纯单文件架构，加载速度极快

## 🛠️ 如何使用
直接通过 GitHub Pages 访问，或下载 `index.html` 在本地浏览器双击打开即可预览。
